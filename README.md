# Craftsman-Cook-Western-Food-CBT

양식조리기능사 필기 CBT. React + TypeScript + Vite의 비공식 정적 학습 앱입니다.

## 구현과 실행

실전 모의시험·랜덤 문제풀이, 절대 종료 시각 타이머·자동 제출·답안 변경,
결과/해설·오답 복습·북마크·통계, JSON/CSV 로컬 등록·검수·검색·내보내기를 제공합니다.
두 모드 모두 답안 선택/채점 후 Space로 다음 문제로 이동하며 마지막 문제에서 자동 제출하지 않습니다.
학습 기준/버전 선택 메뉴와 상단 상시 면책 배너는 없습니다.
모바일 고정 메뉴는 독립 세로 스크롤을 지원합니다.

Node >=22.12 필요. 이 환경에서는 Node 24.22.1 / npm 11.9.0으로 검증했습니다.
`.node-version`은 재사용 기준의 24.19.0 핀을 유지합니다.

```sh
cd /workspace/Craftsman-Cook-Western-Food-CBT
npm ci
npm run dev
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:e2e
```

시스템 Chromium을 사용하는 이 클라우드에서는 아래 명령을 실행했습니다.

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

로컬 기본 base는 `/Craftsman-Cook-Western-Food-CBT/`입니다.
한 클라우드 작업은 이미 격리되어 있으므로 기존 체크아웃을 사용하고 worktree를 만들지 않습니다.

## 시험 설정과 출처

단일 설정: `src/qualification.ts`. 현재 값은 통합 60문항, 60분, 4지선다,
동일 배점 100점 환산, 60점 이상 합격, 과락 없음입니다.
**공식 페이지가 프록시 CONNECT 403으로 차단되어 공식 원문 확인은 미완료입니다.**
학습용 잠정 설정이며 최신 공식 시험 규칙 재현을 보증하지 않습니다.
과목명·시간·채점·합격 기준과 공식 자료 접근 결과는 [출처 문서](docs/SOURCES.md)에 구분해 기록했습니다.
최신 출제기준 적용기간·첨부파일·실기 규칙은 확인하지 않았습니다.

## 문제은행 수와 검수 범위

| 구분 | 기본 JSON 등록 수 |
| --- | ---: |
| 원문 기출 | 0 |
| 복원 | 0 |
| 자체 제작 | 1,000 |
| 위 자체 제작 중 개념 문항 | 103 |
| 위 자체 제작 중 숫자 조건 변형 | 897 |
| 숫자 변형 관리 유형 | 15 (유형당 59~60조건) |
| 검증 대기·제외 | 0 |
| 내부 검수 목표 1,000 대비 부족 | 0 |

통합 과목 `양식 재료관리, 음식조리 및 위생관리`에 1,000개가 등록되어 있습니다.
단원별 수·유형별 수·해시는 [실제 집계](docs/bank-audit.json)에 있습니다.
개념은 AI 일반 지식으로 작성하고 내부 검토했습니다. 숫자 변형 전체는 별도 언어의
역산 검증과 보기·단위 검사를 거쳤습니다. 외부 전문가 검수와 공식 출제기준 대조는
미완료이며, 이를 전문가 검수 완료 기출 1,000개라고 해석하면 안 됩니다.
숫자 변형 89.7%로 실제 시험의 주제·난이도 분포를 재현하지 않습니다.

같은 family는 모의시험에서 우선 한 번만 추출합니다. 로컬 은행에 유형이 부족할 때만
남은 고유 ID로 보충합니다. 랜덤 학습은 전체 등록 문항의 한 순회 내 ID 중복을 방지합니다.
모든 출제 연도·회차는 null입니다. 확인하지 않은 교재나 외부 정답 자료를 인용하지 않았습니다.
작성 위치 링크와 외부 증빙을 구분하며, 민간 사이트 기출을 복제하지 않았습니다.

재생성은 `python3 scripts/generate_bank.py`이며 고정 원고·ID·순서를 사용합니다.
애플리케이션 MIT 고지는 보존했습니다. 새 자체 제작 데이터는 CC BY 4.0이며
AI 보조 작성·저장소 기여자·링크·변경 사실을 표기합니다. 상세 조건은 LICENSE와 출처 문서를 참고하세요.

## 저장과 개인정보

로그인·서버 없이 `western-cook-cbt:v1` namespace의 localStorage를 사용합니다.
응답 최근 5,000개와 시험 최근 30회를 보관하고, 화면 통계도 이 범위입니다.
기록·진행 시험·연습·오답·북마크·로컬 등록 문항을 저장합니다.
저장 실패는 경고하며 손상 원본을 자동 덮어쓰지 않습니다.
백업은 JSON 내보내기이고 **학습 기록 복원 UI는 없습니다**.
확인 후 초기화하면 개인 데이터만 삭제하며 기본 1,000문항은 유지합니다.
브라우저·origin·시크릿 모드·iframe 저장 정책에 따라 기록이 분리되거나 제한될 수 있습니다.
기기 시계를 변경하면 절대 시각 타이머에 영향을 줄 수 있습니다.

## 배포 진행 결과

요청된 기본 흐름은 main push → validate(단위·빌드·PC/모바일) → Pages 자동 배포입니다.
PR은 검증만 하도록 `.github/workflows/pages.yml`을 준비했습니다.
자동 실행과 수동 실행을 중복시키는 별도 스크립트나 자동 재시도는 없습니다.

이번에는 **배포 사전 확인에서 중단**했습니다.

```text
gh api repos/YunSangYeong/Craftsman-Cook-Western-Food-CBT
Get "https://api.github.com/repos/YunSangYeong/Craftsman-Cook-Western-Food-CBT": Forbidden
exit status 1
```

API 접근 차단으로 권한·Pages Source·현재 게시 상태를 확인하지 못했습니다.
최초 파이프라인과 Pages 배포는 실행하지 않았으며 API 재시도·main push·workflow 재실행·
대체 배포를 하지 않았습니다. 코드는 배포를 유발하지 않는 별도 브랜치에 보존할 수 있습니다.
원격 반영 결과와 정확한 커밋은 작업 완료 보고를 참고하세요.

현재 공개 여부는 **미확인**, 이번 변경의 CI/배포는 **미실행**입니다.
예상 기본 주소는 `https://YunSangYeong.github.io/Craftsman-Cook-Western-Food-CBT/`이나
이는 성공한 배포나 공개 화면 확인의 증거가 아닙니다.
사용자가 지금 할 최소 동작: 환경 네트워크 설정에서 `api.github.com` 접근을 허용합니다.
그 후에도 에이전트는 자동 재시도하지 않으며 요청대로 이후 배포 마무리는 사용자가 진행합니다.
Pages 활성화가 실제로 필요한지는 확인하지 못했으므로 필요하다고 단정하지 않습니다.

검사 결과와 검증 한계는 [검증 보고](docs/VALIDATION.md)에 기록합니다.
