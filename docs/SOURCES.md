# 시험 규칙·문항 출처와 이용 조건

확인일: 2026-11-05 (한국 시간). 최신 표준 스킬 v1.4.0과 실제 앱의 기준 커밋은 별개다.

## 공식 규칙 확인 결과

확인하려 한 공식 자료: Q-Net 양식조리기능사 종목별 상세 정보
https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=7910

이 환경에서 실제 요청은 `curl -I --max-time 20`이며, 프록시가
`HTTP/1.1 403 Forbidden`, `curl: (56) CONNECT tunnel failed, response 403`을 반환했다.
공식 페이지 본문·출제기준 첨부파일·최신 개정판을 읽지 못했다.
따라서 아래 수치를 **공식 확인 완료 또는 최신 출제기준 재현으로 주장하지 않는다**.

| 설정 | 앱의 학습용 잠정값 | 공식 원문 확인 |
| --- | --- | --- |
| 자격증 | 양식조리기능사 | 미완료 |
| 필기 통합 과목 | 양식 재료관리, 음식조리 및 위생관리 | 미완료 |
| 문항·형식 | 60문항, 객관식 4지선다 | 미완료 |
| 시간 | 60분 | 미완료 |
| 채점 | 동일 배점, 100점 만점, 정답 수 / 60 × 100 | 미완료 |
| 합격 | 반올림 전 점수 60 이상 (36/60 이상), 과락 없음 | 미완료 |
| 미응답 | 오답으로 처리 | 앱 정책 |
| 선정 | 통합 무작위 추출, 숫자 family 우선 1개 | 앱 정책, 공식 단원별 비율 아님 |

공식 확인 후 수정할 단일 설정 위치는 `src/qualification.ts`다.
실기시험은 이 앱의 범위에 포함하지 않는다. 법령의 보존온도·살균시간 등 확인하지 못한
최신 규제 수치는 문항에 넣지 않았다. 출제기준 적용기간·교재 판·기출 연도·회차도 추정하지 않았다.

## 문제은행의 실제 구성

- 기본 JSON 실등록·내부 검수 완료: **1,000개**. 목표 대비 수량 부족 **0개**.
- 원문 기출 0개, 복원 0개, 자체 제작 1,000개.
- 독립적으로 작성한 개념 문항 103개, 숫자 조건 변형 897개.
- 숫자 변형은 15개 family: 1~3번은 각 59조건, 4~15번은 각 60조건.
- 이 15개는 작성·관리 유형이며 서로 독립적인 수학 개념 15개라는 의미는 아니다.
  비례식·비율의 역산이 여러 조리 맥락에 사용된다.
- 통합 과목 1개에 1,000개가 등록되어 있으며 단원별 정확한 수는 `bank-audit.json`에 기록한다.
- 검증 대기·오류·중복으로 제외된 기본 문항 0개. 사용자의 로컬 등록 문항은 기본 수에서 제외한다.
- 모든 연도·회차는 null이다. 기출을 확보했다는 의미로 제작일을 넣지 않는다.

## 실제 작성 근거·검수 범위

AI 일반 지식으로 개념 원고를 직접 작성했다. 외부 교재나 공식 자료를 읽고 대조했다는
인용은 하지 않았다. 계산형은 문항에 조건·공식·단위·반올림을 명시했다.
에너지 환산 계수 등도 문항 안의 주어진 가정이며 공식 영양표시 검증을 대신하지 않는다.
`sourceUrl`의 이 저장소 링크는 **작성 위치**이며 외부 정답 증빙이 아니다.

개념 문항은 내부적으로 질문의 조건, 정답과 오답의 구별, 해설 문장을 검토했다.
자동 검사는 ID·본문/정렬된 보기의 정규화 중복, 형식, 보기 개수, 정답 번호,
연도·회차 부재를 검사한다. 숫자 변형 897개 전체는 Python Decimal 전방 계산과
별도로 작성한 TypeScript 역산 관계를 대조한다. 보기의 단위·정답 대응·동치 수치도 검사한다.

의미 검토에서는 같은 산술 관계의 반복을 family로 공개하고 서로 비슷한 조리 개념도
숨기지 않는다. 의미상 중복의 완전한 부재를 자동 검사만으로 보증하지 않는다.
숫자 변형이 전체의 89.7%로 많아 실제 시험의 난이도·주제 비중·교육적 다양성을 재현하지 않는다.
모의시험은 family별 한 개를 우선 뽑으며, 전체 기본은행에는 103개의 비변형 문항도 있어
한 시험에서 동일 family를 중복 선정할 필요가 없다. 로컬 가져오기로 유형이 부족해진
은행은 필요한 나머지를 서로 다른 ID로 보충한다.

**내부 검수와 외부 전문가 검수·공식 기준 대조는 다르다.** 후자 두 가지는 미완료다.
이 1,000개를 전문가 검수 완료 기출 은행이라고 부르지 않는다. 공식성·학습 범위 검증은
여전히 미완료이며, 관련 전문가의 후속 검토가 필요하다.
